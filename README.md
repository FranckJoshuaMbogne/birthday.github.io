# For my little bird 🐦

A birthday memories website. Everything inside (text and photos) is encrypted and opens only with the secret code.

- **Site:** `index.html`
- **Editor:** `admin.html`. Open it, enter the code, edit, then press **Publish**.
  Publishing needs a GitHub fine-grained token with *Contents: Read and write* on this repo only (see the Settings tab in the editor).
